# 集成事件

放在**发布方** `Application.Contracts/Events`，继承现有 `EventEntity<T>`。主题名拆服务后不改。

命名：`pot.{context}.{event}.v1`  
投递：CAP + RabbitMQ。**设备指令不走 CAP。**  
消费：`IMessageTracker` 幂等。

| 主题 | 发布 | 订阅 | 订阅方做什么 |
|---|---|---|---|
| `pot.asset.sn.inbound.v1` | Asset | — | V1 可无订阅 |
| `pot.asset.sn.outbound.v1` | Asset | AfterSales | 质保起算可缓存 |
| `pot.asset.sn.status.changed.v1` | Asset | Device, AfterSales | 维修中禁止新绑定 |
| `pot.device.bound.v1` | Device | Asset | SN → Bound |
| `pot.device.unbound.v1` | Device | Asset | SN → Outbound（仍属会员） |
| `pot.device.online.v1` | Device | Cooking | 等待中可继续 |
| `pot.device.offline.v1` | Device | Cooking | 超时策略 |
| `pot.device.shadow.changed.v1` | Device | Cooking | **只展示/看门狗，不当投料扳机** |
| `pot.device.slot.bound.v1` | Device | Inventory | 更新放置投影 |
| `pot.device.slot.unbound.v1` | Device | Inventory | 清空投影 |
| `pot.device.command.acked.v1` | Device | Cooking | 推进步骤 |
| `pot.cooking.task.completed.v1` | Cooking | Inventory | 投放成功才扣账本 |
| `pot.cooking.task.failed.v1` | Cooking | Inventory | 缺料不扣 |
| `pot.aftersales.ticket.opened.v1` | AfterSales | Asset, Device | SN→Repairing；必要时解绑 |
| `pot.aftersales.ticket.closed.v1` | AfterSales | Asset | 回库/换货/报废 |

扣减：仅 `DISPENSE + SUCCESS`。`MISSING` 不扣。
