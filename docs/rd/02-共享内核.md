# 共享内核

只放协议级稳定类型。路径建议：`src/Shared/NXAI.Shared.Pot`（或 `NXAI.Shared/Pot/`）。

**禁止**把 Device / Recipe / Product / AssetSn 实体放进来。

| 类型 | 取值 |
|---|---|
| `DispenseMode` | `WEIGHT` / `PACKAGE` / `COUNT` / `TIME` |
| `TriggerType` | `TEMP_GTE` / `TEMP_LTE` / `DELAY` / `IMMEDIATE` |
| `AmountUnit` | `G` / `PACK` / `PCS` / `SEC` |
| `CommandAction` | `DISPENSE` / `HEAT` / `KEEP_WARM` / `STOP` / `PING` |
| `CommandResultCode` | `RECEIVED` / `RUNNING` / `SUCCESS` / `FAILED` / `MISSING` / `EXCEPTION` / `REJECTED` |
| `SlotType` | `BULK` / `PACKAGE` / `CARTRIDGE` |
| `PotMqttEnvelope` | 见 [protocol/mqtt](protocol/mqtt.md) |
| `TelemetryPoint` | 见 [protocol/telemetry](protocol/telemetry.md)（也可放 Device.Contracts，不要放业务实体） |

ID 继续用 `long` 雪花。审计继续用 `EfFullAuditEntity`。
